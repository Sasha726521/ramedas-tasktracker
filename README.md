# TaskTracker - тестова копія

Інтерфейс: https://sasha726521.github.io/ramedas-tasktracker/

Окремий тестовий сервер ще потребує розгортання. Робочий API відключено, Excel не імпортовано. Без сервера вхід недоступний.

## Google Apps Script

1. Створити окремий Apps Script у власному Google-акаунті.
2. Вставити Code_v5_api.gs у Code.gs і зберегти.
3. Запустити setupTestEnvironment та надати потрібні дозволи. Функція створить нову таблицю, структуру листів і тестового адміністратора.
4. Посилання на таблицю буде в журналі виконання. Логін testadmin, випадковий пароль у Users!E2.
5. Deploy > New deployment > Web app. Execute as: Me. Who has access: Anyone. Цей API призначений лише для вигаданих тестових даних: оригінальна перевірка прав довіряє caller, повноцінних серверних сесій немає.
6. Скопіювати URL /exec у вікно налаштування на сайті. Увійти, створити тестову задачу та перевірити збереження після перезавантаження.

Telegram, пошта та календар не налаштовані. Не додавати корпоративні токени, користувачів чи дані.

## Зміни для запуску

- Вилучено адресу робочого API та CNAME.
- Окремий ключ налаштувань тестового API.
- Вимкнено неявний деморежим замість справжнього сервера.
- Виправлено відносні шляхи Pages і межі очищення кеша.
- Вилучено неіснуючий TextOutput.setHeader.
- Публікується лише docs/; серверний .gs зберігається в репозиторії.
